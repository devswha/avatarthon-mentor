# 작업 메모

멘토 과제를 Claude Code(코딩 AI, Opus 5.5)와 대화하며 만든 과정. 대화 기록 원문은 같은 폴더의 Claude Code 기록 파일에 있다.

## 요청

"과제 레포를 보고 해야 할 걸 다 해줘"라고 맡겼다. AI가 처음에 물어본 것과 고른 답:

- 이미 만든 게임이 있나 → 없음, 새로 만든다
- 소품 도구 → Blender (Blender를 설치하고 파이썬 스크립트로 모델링)
- 게임 종류 → 장애물 달리기 + 별 수집 (행사 날 아이들이 따라 만들 수 있는 규모)
- 닉네임 → devswha

## 만든 순서

1. **기획**: 4구역짜리 장애물 달리기. 구역마다 새 장치 하나씩.
   1구역 계단 점프 → 2구역 버섯 트램펄린 → 3구역 용암 다리와 사라지는 유리 발판 → 4구역 회전 막대와 구름길 → 트로피.
   별 20개, 체크포인트 3개. 캐릭터 기본값(걷기 16, 점프 약 7칸)에 맞춰 간격은 2~6칸, 한 번에 올라가는 높이는 2칸 이하로 잡았다.
2. **소품(Blender)**: 별·버섯·깃발·트로피·구름 5종을 Blender 5.2.4에서 스크립트로 만들고 FBX·GLB로 내보냈다.
   이름 규칙(`StarCoin_Body`, `JumpMushroom_Cap` ...)을 먼저 정해, 게임 스크립트가 이름으로 소품을 찾게 했다.
3. **게임 스크립트(Luau)**: 서버(규칙), Blender 소품 붙이기, 클라이언트(화면·조작), 설정 모듈로 나눴다.
4. **게임 파일**: 코스 배치와 스크립트를 합쳐 `.rbxlx`를 만드는 파이썬 생성기를 썼다.
5. **점검**: Studio가 없어 코드를 직접 돌려 볼 수 없었다. 그래서 두 가지로 확인했다.
   - 다른 AI 에이전트에게 Luau 코드만 주고 따로 검토하게 했다. 고칠 점 5개를 받아 모두 고쳤다.
   - 코스를 Blender로 그려 배치를 눈으로 확인했다(`layout-course_*.png`). 그걸 보고 트로피를 6칸에서 8칸으로 키웠다.

## 도구를 어디에 썼나

| 부분 | 도구 |
|---|---|
| 별·버섯·깃발·트로피·구름 소품 | Blender (파이썬 스크립트로 모델링, FBX/GLB 내보내기) |
| 코스 발판·용암·유리 발판·회전 막대·표지판 | 스튜디오 기본 파트 (생성기가 `.rbxlx`에 직접 씀) |
| 게임 규칙·화면 | Luau 스크립트 |
| 소품을 못 불러왔을 때 대신 보이는 모양 | 기본 파트 (금화, 원기둥 버섯, 막대 깃발 등) |

## 설계에서 정한 것

- **충돌은 기본 파트, 보이는 건 메시**: 버섯 윗면, 구름 바닥, 별 판정 상자는 보이지 않는 기본 파트다. Blender 메시는 충돌을 끈다.
  메시 모양이 바뀌어도 난이도가 그대로라서 아이들이 소품을 바꿔 끼우기 쉽다.
- **소품 교체는 Import 3D 한 번**: FBX 하나에 소품 5종을 다 넣었다. Studio에서 한 번만 가져오면 `BlenderProps` 스크립트가 크기를 맞춰 코스 곳곳에 복사한다.
- **별은 사람마다 따로**: 친구가 먹어도 내 화면의 별은 남는다. 여럿이 해도 서로 뺏지 않는다.
- **회전 막대는 내 화면 기준 판정**: 모든 화면이 같은 서버 시계로 막대를 돌리고, 내 캐릭터가 막대에 닿았는지는 내 화면에서 본다. 인터넷이 느려도 보이는 대로 맞는다.

## 막힌 곳

1. **리눅스라 Roblox Studio가 없다**: `.rbxlx`가 XML이라는 점을 이용해 파이썬으로 직접 썼다(속성 이름 `size`, `shape`, `Color3uint8` 같은 XML 규칙에 맞춤).
2. **Rojo·luau-lsp 실행이 권한 검사에 막혔다**: 내려받은 실행 파일을 돌리는 단계가 자동 권한 검사에서 막혔다. 우회하지 않고 생성기를 직접 만들었다. 문법·타입 자동 검사 대신 다른 에이전트의 코드 검토를 받았다.
3. **회전 막대가 안 돌 뻔했다**: 서버 시계(1970년부터 센 초)에 속도를 곱하면 각도가 약 25억 라디안이 된다. CFrame은 낮은 정밀도로 계산해서 몇 분에 한 번씩만 움직일 수 있었다. 각도를 한 바퀴(2π) 안으로 줄인 뒤 넣어서 고쳤다.
4. **다시 하기 직후 또 골인**: 이전 캐릭터가 아직 골인 발판 위에 있어 골인이 다시 잡힐 수 있었다. "3번 체크포인트를 지나야 골인"이라는 조건을 넣어 막았다.
5. **Blender 별이 누웠다고 나옴**: 정오각형 별은 원래 키보다 폭이 5% 넓다. 그래서 "가장 긴 축 = 위쪽" 검사에서 떨어졌고, 폭을 조금 줄였다.
6. **미리보기 조명**: 처음 렌더는 하얗게 날아가고 뒤에서 비춘 조명이 긴 그림자를 만들었다. 조명 세기를 거리에 맞춰 다시 계산하고 보조 조명의 그림자를 껐다.
7. **구름 모양**: 공 여러 개를 합친 메타볼이 땅콩처럼 울퉁불퉁했다. 가운데 덩어리와 둘레 덩어리 크기를 맞추고 윗면을 부드럽게 눌러 밟을 수 있게 했다.

## 사람이 직접 해야 하는 일 (AI가 못 하는 것)

- Studio에서 `.rbxlx` 열기 → Import 3D로 `AvatarthonProps.fbx` 넣기 → 플레이해 보기
- Publish to Roblox로 올려 게임 주소 받기
- 말로 설명하며 1~3분 플레이 영상 찍기
- 플레이 소감과 아이에게 알려 줄 것을 내 말로 쓰기
